# exceedone/exment-admin-core

Admin UI framework (grid / form / show / tree / widgets) that powers the
[Exment](https://exment.net) admin panel.

> **Note**
> This source code is **based on [laravel-admin](https://github.com/z-song/laravel-admin)
> and [open-admin-core](https://github.com/open-admin-org/open-admin)**, and has been
> **modified** for Exment — including the upgrade to **Laravel 13 / PHP 8.3** and the
> namespace rename `OpenAdminCore\Admin` → `ExmentAdminCore\Admin`.

## Package

| | |
|---|---|
| Package | `exceedone/open-admin-core` |
| Namespace | `ExmentAdminCore\Admin\` → `src/` |
| Service provider | `ExmentAdminCore\Admin\AdminServiceProvider` |
| Facade alias | `Admin` |
| Requires | PHP `^8.3`, Laravel `13` |
